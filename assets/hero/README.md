# Homepage Background Photograph

These files are compressed variants of the existing homepage photograph:
https://images.unsplash.com/photo-1557804506-669a67965ba0

Source license: https://unsplash.com/license (commercial website use permitted).
This is an illustrative photograph, not a representation of company employees.

Rebuild with `python -B tools/fetch_hero_assets.py`. The generated manifest records
each source URL, dimensions, encoding quality, byte count, and SHA-256 digest.
AVIF variants serve modern browsers; JPEG variants provide the fallback.
